19:4
[翻訳注] ヘブル語本文において、神名（אֱלֹהִים, ’elohim）と形容詞（קְדֹשִׁים, qÿdoshim、「聖なる」）の双方が複数形である。唯一の真の神を指す場合、神名は通常単数の修飾語を取るが、これは形容詞が尊称複数名詞と文法的に一致している例外である。GKC §124.i および IBHS 122 を参照。
[翻訳注] In the Hebrew text both the divine name (אֱלֹהִים, ’elohim) and the adjective (קְדֹשִׁים, qÿdoshim, “holy”) are plural. Normally the divine name, when referring to the one true God, takes singular modifiers, but this is a rare exception where the adjective agrees grammatically with the honorific plural noun. See GKC §124.i and IBHS 122.
