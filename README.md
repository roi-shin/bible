# 聖書プロジェクト (NET Bible 日本語対訳)

NET Bibleの英語テキストと注釈をスクレイピングし、生成AIを利用して日本語に翻訳した上で、美しく読みやすい静的サイト（HTML/CSS/JS）を自動生成するプロジェクトです。

## 使い方

メインスクリプト `scrape_and_translate.py` を実行することで、データの取得・翻訳・HTMLの一括生成が行われます。

### 1. 基本的な実行方法

本（Book）の名前と章番号を指定して、1章だけを処理します。

```bash
python scrape_and_translate.py Genesis 1
```

### 2. 範囲指定での実行（複数章の一括処理）

ハイフン `-` またはチルダ `~` を使うことで、指定した範囲の章を連続で処理できます。

```bash
python scrape_and_translate.py Genesis 4-10
```

### 3. 本全体（1冊まるごと）の実行

章番号を省略すると、その本の1章から最終章までをすべて連続で処理します。

```bash
python scrape_and_translate.py Genesis
```

### 4. 【重要】APIモードの利用（制限回避）

デフォルトではローカルの `agy` CLI を経由して翻訳を行いますが、背後で動くAIのトークン制限を回避するため、Gemini APIを直接叩く `--api` フラグが用意されています。
より安定して処理を進めるため、基本的にはこちらの使用をおすすめします。

```bash
python scrape_and_translate.py Genesis 4-10 --api
```
### 5. 空白を含む場合
「1 Samuel」のように名前に空白（スペース）が含まれる書物を指定する場合は、ダブルクォーテーション " またはシングルクォーテーション ' で書名を囲んで実行します。

以下のようにコマンドを入力してください！

bash
#### 1章のみ実行する場合
python scrape_and_translate.py "1 Samuel" 1 --api
#### 1〜10章を範囲指定で実行する場合
python scrape_and_translate.py "1 Samuel" 1-10 --api


> **💡 効率的な並列処理の目安**
> APIの制限（1分間に5リクエストまで）を回避するため、ターミナルを複数開いて並列実行する場合は**「2並列（ターミナル2つ）」まで**に留めるのが最も安全かつ効率的です。1日20章まで

---

## 出力されるファイル

スクリプトの実行が完了すると、以下のフォルダにデータが自動で生成・更新されます。

- **`data/`**
  翻訳済みの中間JSONデータと、ローカルAI検索用のMarkdownファイル（日・英）が各章ごとに保存されます。
- **`docs/`**
  完成した静的サイトのファイル一式（`index.html`、各章ごとのHTML、CSS、JS）が出力されます。このフォルダをサーバー等にアップロードするだけで、サイトをそのまま公開できます。
